# paris-ozone-time-series-forecasting
Time Series Analysis and Forecasting of Ground-Level Ozone (O₃) Concentrations in Paris Using Machine Learning. The project includes data collection from the OpenAQ API, exploratory data analysis (EDA), time series decomposition, forecasting models, and an interactive dashboard.
